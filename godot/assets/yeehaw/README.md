# YEEHAW! by CURSED OFFERINGS

These are the original files of the "YEEHAW!" western tileset by **CURSED OFFERINGS**.
They are included here only so this project can be opened and the game's graphics rebuilt.

**If you want to use them in your own project, please download them from the author's page**
(pay what you want, so you can support the author there):
https://cursed-offerings.itch.io/yeehaw

The author's terms (from that page): "DO customise, modify, and use these assets in commercial or
non-commercial projects of any kind."
