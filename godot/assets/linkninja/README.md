# Pixelart Cowboy by LinkNinja

These are the original files of the "Pixelart Cowboy" asset pack by **LinkNinja**.
They are included here only so this project can be opened and the game's graphics rebuilt.

**If you want to use them in your own project, please download them from the author's page:**
https://linkninja.itch.io/pixelart-cowboy

The author's terms (from that page): "Feel free to use this in any project, no credit needed."
